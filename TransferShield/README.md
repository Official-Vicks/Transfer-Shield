# TransferShield

Payment verification and transaction-trust infrastructure.

## Problem

Merchants can receive fraudulent payment confirmations,
including fake screenshots or mismatched transaction details.

## Goal

TransferShield provides an API for verifying payment events
and determining whether they correspond to an expected payment.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Pytest
